# Part D: Prediction GUI (Mandatory)

Simple GUI (e.g., Streamlit, Gradio, or Tkinter) where the user can:
1. Enter numerical values (Part A regression prediction)
2. Upload an image (Part B flower classification prediction)
3. Type text (Part C text classification prediction)

**Rule:** Load pre-trained models and preprocessors from `models/` via `joblib` — do **not** retrain models inside the GUI.
