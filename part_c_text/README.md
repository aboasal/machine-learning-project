# Part C: Text Data (Classification)

**Owners:** Omar Mohamed & Yasser

## Scope
- Models: Logistic Regression and Linear SVM.
- Steps: Text cleaning (lowercasing, removing punctuation, numbers, stopwords, HTML tags), feature extraction (Bag of Words or TF-IDF), validation-set hyperparameter tuning, and single test-set evaluation (Accuracy, Confusion Matrix, Precision, Recall, F1-score per class).
